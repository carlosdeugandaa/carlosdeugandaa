## 👨‍💻 About Me

Hello! I'm **carlosdeuganda** — also known as **Wanyale Charles Mark**. I'm a self-taught developer from Uganda 🇺🇬 who discovered the magic of code in 2025. What started as a spark of curiosity has grown into a blazing passion for building digital solutions that make a real difference.

### The Beginning

In 2025, I wrote my first line of code — a simple `<h1>` tag that said "Hello World." That small moment changed everything. I realized that with just a few keystrokes, I could create something visible, something that existed where nothing did before. That feeling was addictive.

I devoured everything I could find — free tutorials, documentation, YouTube videos, and countless hours of practice. I built my first landing page, then a portfolio, then a simple blog. Each project taught me something new. Each bug taught me patience. Each solution taught me resilience.

### Today (2026)

Two years into my coding journey, I've evolved from a curious beginner to a developer who can architect complete web applications. I'm proficient in:

- **Frontend Development:** HTML, CSS, JavaScript, React, Tailwind CSS, Bootstrap
- **Backend Development:** PHP, MySQL, Node.js, Express
- **Design & Tools:** Figma, VS Code, Git, GitHub
- **Modern Skills:** Responsive Design, API Integration, Problem Solving

But more than the technologies I know, I've learned how to think like a developer. I've learned to break problems into pieces, to ask the right questions, to persist when things get hard, and to celebrate the small wins.

### What Drives Me

Every day, I wake up excited to learn something new. Whether it's a new React hook, a cleaner way to structure PHP code, or a design pattern I've never seen before, I'm driven by the thrill of discovery.

I believe technology should be accessible, beautiful, and useful. I want to build products that people love to use. I want to help businesses tell their stories through thoughtful design. I want to contribute to open source and give back to the community that taught me so much.

### Looking Ahead

My journey is still young but already full of momentum. I'm currently working on:

- Mastering advanced React and Next.js for building scalable applications
- Deepening my backend expertise with Node.js and cloud architecture
- Building projects that solve real problems for real people
- Contributing to open source projects that align with my values
- Helping businesses in Uganda and beyond establish their digital presence

I started in 2024, but I'm building for the long haul. This is just the beginning.

> 💡 "The best product starts with solving one real problem. The rest is just code."
